Short Introduction:
-

Welcome to File-Sharings documentation! This website is dedicated to helping you get to know the code base and understand how file-sharing works. 
Now if you dont know what file sharing is, you are in the right place! File sharing is a file sharing platform that uses a central server to coordinate users to share files through p2p.
This project focuses on networking concepts such as TCP, UDP, NAT hole punching and reliable packet delivery.

What does it do:
-

  -   File sharing currently is unable to share files (Ik ironic its called file sharing and cant even do what its named after).
  -   But currently we are able to host a server which keeps track of all users that leave and join. This server also updates users in real time whether a user has joined or left the current server.
  -   We also have a client program which is able to join to a hosted server through ip:port. These clients can (Logically) connect to another client.
